# EdgeVision: Real-Time Edge-Based Object Detection

EdgeVision is an edge-based computer vision project designed for real-time object detection and tracking using YOLOv8 and OpenCV. By processing video feeds locally on edge devices, the system achieves low latency, reduced bandwidth usage, and high computational efficiency.

## 📌 Features
- **Real-Time Detection:** Rapid object identification powered by YOLOv8.
- **Edge-Optimized:** Designed to run efficiently on local hardware without cloud dependency.
- **Video Stream Processing:** Handles live camera feeds and pre-recorded video streams via OpenCV.
- **Modular Codebase:** Clean structure allowing easy integration of new vision models or custom datasets.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Computer Vision:** OpenCV
- **Deep Learning Framework:** Ultralytics YOLOv8
- **Numerical Processing:** NumPy
